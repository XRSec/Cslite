# 注意事项

1. **轻量架构定位**：服务端基于 TypeScript + Hono，无 Redis/消息队列与后台常驻调度循环；任务由用户通过 API/Web 写入数据库，Agent 定时轮询 `/api/agent/commands` 原子抢占执行并上报 `/api/agent/result`。
2. **Cookie 与 HTTPS 安全**：会话 Cookie 名称为 `cslite_session`（`HttpOnly; SameSite=Lax`）。服务端会根据请求 URL 或 `X-Forwarded-Proto` 自动判断是否附加 `Secure` 属性（也可通过 `CSLITE_COOKIE_SECURE` 显式覆盖）；在 HTTP 本地开发以外的生产环境强烈建议通过 HTTPS / 反代 / Cloudflare Workers 访问。
3. **默认管理员凭据**：首次访问 `/api/*` 时 `ensureMigrated` 会自动建表并创建管理员账号（默认 `admin / admin`，可通过 `CSLITE_ADMIN_USERNAME`、`CSLITE_ADMIN_PASSWORD` 指定）。上线前请务必设置强密码并修改默认凭据。
4. **数据库方言兼容性**：所有 SQL 严格兼容 SQLite（`node:sqlite` / Cloudflare D1 / Turso）与 MySQL（`mysql2`），禁止引入方言专属语法（如 `JSON_CONTAINS`）；目标关联统一通过 `command_targets` 规范表查询。
5. **Cloudflare Workers 注意事项**：`server/src/app.ts` 与路由层严禁导入 Node 专属模块或 `mysql2`；`GET /health` 为零数据库、零 CPU 开销探测端点。部署前需先执行 `make build-web` 更新 `server/src/ui-bundle.ts` 并运行 `wrangler d1 migrations apply`。
6. **OpenWrt 存储与极简模式**：OpenWrt `/var` 为内存 tmpfs，Go Agent 与 `cslite-agent-lite.sh` 均默认将 `config.json` 与 `state.json` 持久化在 `/etc/cslite-agent/`。4MB/8MB Flash 设备建议使用 `cslite-agent-lite.sh` 或 `.ipk` 精简包。
